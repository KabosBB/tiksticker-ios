# استيكرات تيك توك ← واتساب (نسخة الآيفون)

## ١. بناء ملف الـ IPA على GitHub (ببلاش)

1. ادخل github.com واعمل repo جديد (New repository)، مثلًا `tiksticker-ios`. ممكن يكون Private.
2. في صفحة الـ repo دوس **uploading an existing file**.
3. فك ضغط `TikSticker-iOS.zip` واسحب **كل اللي جوه الفولدر** (بما فيهم فولدر `.github`) لصفحة الرفع، وبعدين دوس **Commit changes**.
   - لو الويندوز مخبّي فولدر `.github`: من File Explorer ← View ← فعّل Hidden items.
4. افتح تبويب **Actions**. هتلاقي البناء اشتغل لوحده وبياخد حوالي ١٠ دقايق.
5. لما يخلص بعلامة ✓ خضرا، افتحه وانزل لتحت عند **Artifacts**، ونزّل `TikSticker-ipa`. هتلاقي جواه `TikSticker.ipa`.
   - لو طلع ✗ أحمر، افتحه وابعتلي آخر الأخطاء اللي فيه.

## ٢. تثبيته على الآيفون من الويندوز

1. نزّل وثبّت **Sideloadly** من sideloadly.io، وثبّت **iTunes** و**iCloud** من موقع أبل (مش من Microsoft Store).
2. وصّل الآيفون بالكابل ودوس "Trust" على الموبايل.
3. افتح Sideloadly، واسحب فيه ملف `TikSticker.ipa`، واكتب الـ Apple ID بتاعك، ودوس **Start**.
4. على الآيفون: الإعدادات ← عام ← VPN وإدارة الأجهزة ← دوس على الـ Apple ID بتاعك ← **ثقة**.
5. لو الآيفون iOS 16 أو أحدث: الإعدادات ← الخصوصية والأمان ← **وضع المطوّر** ← فعّله والموبايل هيعمل ريستارت.

ملحوظة: بحساب Apple ID المجاني، الأبلكيشن بيشتغل ٧ أيام بس. بعدها كرر خطوة ٣ من Sideloadly، والاستيكرات اللي عملتها مش هتتمسح.

## ٣. الاستخدام

1. افتح تيك توك وروح للكومنت اللي فيه الاستيكر.
2. من مركز التحكم دوس على زرار تسجيل الشاشة ⏺، وسجّل ٣ ثواني والاستيكر ظاهر.
3. افتح الأبلكيشن ودوس **اختار فيديو تسجيل الشاشة**.
4. حط المربع على الاستيكر ودوس **اعمل الاستيكر**، وبعدين **ضيفه لواتساب**.
